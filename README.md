One original dad joke for make.fun's "The One-Liner Groan-Off" bounty ($2 in USDC, top 10 places share). `main.py` writes the joke to `/output/entry.txt` — one line, 92 characters, inside the 140-character gate.

> I asked my wife what she wanted for dinner. She said, 'Surprise me.' So I hid the leftovers.

## Run it

```sh
python3 main.py
```

With `MAKEFUN_OUTPUT_DIR` set, the entry lands at `$MAKEFUN_OUTPUT_DIR/entry.txt`; otherwise it writes to `/output/entry.txt`.

## Why this joke

A dinner-table dad setup with a fast twist: "surprise me" is taken literally, so the surprise is hidden leftovers. Short, fresh, and groan-worthy — the punchline lands in the last clause.
